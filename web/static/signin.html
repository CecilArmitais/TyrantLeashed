Getting your login data from the official game
  1. Open the game in Chrome as you always do, then press F12 and pick the Network tab.
  2. Reload the page and let the game load.
  3. Right-click any row in the list and choose Save all as HAR with content.
  4. Choose that file here.

This page reads the file on your computer and sends only your game data: your passwords and Kongregate session in it stay with you.
